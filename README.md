**新しい3本柱**
1. 定期借地権マンションの営業支援
2. 新人研修

- 個別マンション特化 → **全体支援**

## アーカイブ：旧モデル時点の提案（リビオ上野池之端）

リビオ上野池之端（旧・水月ホテル鴎外荘跡地／不忍池・**普通借地権**）向けの、坪単価比較以外に提案すべき7カテゴリ。

1. 借地「5大不安」払拭コンテンツ
2. 相続税評価メリットの"資産家"訴求
3. 立地・歴史の希少性ストーリー
4. 住戸別・客観的「将来価値レポート」
5. 多軸の競合比較
6. ターゲット別シミュレーションの出し分け
7. 販売プロセスへの"仕組み"提供

※ 当初は一般定期借地権と想定していましたが、普通借地権であることが判明しています。
