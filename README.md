# 定借新築マンション 個別販売コンサル 付加価値提案

**リビオ上野池之端（旧・水月ホテル鴎外荘跡地／不忍池・一般定期借地権）** の個別販売・販売コンサルティングに向けた、事業主向け提案骨子です。

> 定期借地権マンションは「比較」では売れない。「不安の払拭」と「納得のデータ」で売る。

## 内容：坪単価比較以外に提案すべき7カテゴリ

1. 定借「5大不安」払拭コンテンツ（最優先・独自）
2. 相続税評価メリットの"資産家"訴求
3. 立地・歴史の希少性ストーリー
4. 住戸別・客観的「将来価値レポート」（定借ナビ本領）
5. 多軸の競合比較（坪単価は1軸にすぎない）
6. ターゲット別シミュレーションの出し分け
7. 販売プロセスへの"仕組み"提供（コンサルの核）

## 実装に必要なデータと入手フラグ

各Proposalをサービス化するために必要なデータを、粒度と入手難易度でフラグ分けした一覧表を追加。

- **1 既存**：定借ナビ保有（成約単価・新築比 等）
- **2 取得可**：公開データからスクレイピング可能（路線価・賃料・金利 等）
- **3 一次情報**：自分たちで取りに行く必要あり（重要事項説明書・登記・自社KPI 等）
- **4 分類不可**：生データでなく設計・入力値（補正係数・スコア化ルール 等）
